# هوش مصنوعی؛ از شناخت تا کاربرد

یک سند فارسی، تعاملی و تک‌فایلی که هوش مصنوعی را از بالا به پایین برای خوانندگان
غیرفنی و مدیران توضیح می‌دهد. خروجی نهایی `dist/index.html` است: یک فایل مستقل
که بدون شبکه، از روی فلش یا پیوست ایمیل باز می‌شود.

## باز کردن سند

`dist/index.html` را در مرورگر باز کنید. هیچ سرور، نصب یا اتصالی لازم نیست.
همهٔ فونت‌ها، شکل‌ها، استایل‌ها و اسکریپت‌ها داخل همان یک فایل هستند.

## ساخت مجدد

```bash
npm install
npm run build
```

`npm run build` این کارها را انجام می‌دهد:

1. `scripts/check-skeleton.ts` — ۳۵ درس، شناسه‌ها، ترتیب، فراداده، شکل‌ها و لنزهای کانتکست را می‌سنجد.
2. `scripts/check-glossary.ts` — قواعد واژه‌نامه را اجرا می‌کند: `not_before`، نخستین کاربرد،
   لاتین ناشناس و وضعیت تأیید.
3. `scripts/check-context.ts` — دادهٔ لنزها را می‌سنجد: گشایش نوع بلوک‌ها، متن روایت،
   JSON، ثابت‌های داستان، سقف کنترل‌ها و تطابق فراداده با بدنه.
4. `astro build` — سند را می‌سازد و با `vite-plugin-singlefile` همه‌چیز را در
   `dist/index.html` درون‌خطی می‌کند.
5. `scripts/check-budget.ts --post` — بودجهٔ واژه و اندازهٔ خروجی را می‌سنجد و
   بررسی می‌کند که `dist` فقط یک فایل داشته باشد.

برای توسعه:

```bash
npm run dev
npm run check
```

## نوشتن یک درس

هر درس یک فایل MDX در `src/content/lessons/` است. فراداده با
`src/content.config.ts` اعتبارسنجی می‌شود. ساختار بدنه:

```mdx
یک پاراگراف قلاب که مسئله را می‌سازد.

<ComponentName id="fig-2-3" caption="..." desc="..." ... />

متن توضیح مکانیزم.

<Takeaway>جملهٔ پایانی.</Takeaway>
```

قواعد مهم:

- شکل‌ها با داده به کامپوننت داده می‌شوند؛ SVG دستی در درس نوشته نمی‌شود.
- درس‌های ۱.۲ و ۶.۴ شکل اصلی ندارند؛ به نقشهٔ فهرست ارجاع می‌دهند. فیلد `figure` اختیاری است.
- `caption` باید همان `figure.caption_fa` در فراداده باشد و *نکتهٔ* شکل را بگوید.
- `desc` توصیف واقعی شکل برای خوانندهٔ صفحه‌خوان است، نه تکرار caption.
- واژه‌ها در نخستین کاربرد با `<Term id="..." />` می‌آیند؛ بعد از آن شکل کوتاه.
- شناسه‌های لاتین داخل متن با `<Ltr inline>` ایزوله می‌شوند.
- ارقام متن فارسی‌اند؛ ارقام لاتین فقط در کد و جدول‌های اندازه‌گیری.

## فهرست و نقشهٔ ناوبری

دکمهٔ ثابت فهرست، نقشه‌ای با شش ناحیهٔ رنگی باز می‌کند. همهٔ ۳۵ درس و ۵۳ مفهوم
پیوند مستقیم دارند. جست‌وجو با نام فارسی یا انگلیسی، شمارهٔ درس و ارقام فارسی کار می‌کند.
درس جاری مشخص است؛ انتخاب یک مقصد، فهرست را می‌بندد و تمرکز را به محتوای مقصد می‌برد.

نقشه دیگر در درس‌ها یا ابتدای بخش‌ها تکرار نمی‌شود. نمایش آن در
`src/components/shell/TocMap.astro` و رفتار آن در `src/scripts/toc.ts` است.
بدون جاوااسکریپت، همان پیوندها در یک فهرست جمع‌شوندهٔ بومی در دسترس‌اند.


## لنزهای کانتکست

بیست درس یک **لنز کانتکست** دارند و درس ۴.۳ یک **آزمایشگاه کانتکست**. لنز، شکل دوم همان درس است
(شکل اصلی را عوض نمی‌کند) و نشان می‌دهد مدل در آن لحظه دقیقاً چه متنی می‌بیند، هر تکه را چه کسی
نوشته، و مدل چه ادامه‌ای می‌نویسد. جملهٔ پایانی همهٔ لنزها یکی است:
«مدل فقط ادامهٔ متنی را می‌نویسد که جلویش گذاشته‌اند.»

برای افزودن یا عوض‌کردن یک لنز:

1. بلوک‌های داستان را در `src/data/context/blocks.ts` تعریف یا ویرایش کنید (متن، نوع، توکن تقریبی).
2. لنز را در `src/data/context/lenses.ts` بسازید: `key`، `lesson`، `mode` و گام‌ها. اگر نوع بلوک
   تازه‌ای لازم است، آن را در `src/data/context/kinds.ts` با `introducedIn` درست اضافه کنید.
3. در فرادادهٔ درس `context_lens` را بنویسید و در بدنه، بعد از متن توضیحی و پیش از
   `<Takeaway>`، `<ContextLens ... />` را صدا بزنید (برای ۴.۳: `<ContextLab ... />`).
4. `node scripts/check-context.ts` را اجرا کنید. این ابزار مطمئن می‌شود هیچ واژه‌ای پیش از
   `not_before` نیامده، JSON معتبر است و گام‌ها روایت یک‌جمله‌ای دارند.

قواعد مهم: هر بلوک فقط متن است؛ اجرای ابزار، جست‌وجو و نوشتن حافظه در ستون «بیرون از متن»
می‌آید. خروجی‌ها نمونهٔ ساخته‌شده‌اند، نه خروجی مدل زنده. `نمای خام` همهٔ برچسب‌ها را برمی‌دارد
تا همان متن پیوسته دیده شود. بدون JS، چاپ و کاهش حرکت، همهٔ گام‌ها با هم نشان داده می‌شوند.

## واژه‌نامه و اعتبارسنجی

`glossary.yml` منبع واحد واژه‌هاست. هر واژه `not_before` دارد؛ استفاده پیش از
معرفی، ساخت را متوقف می‌کند. `check-glossary.ts` چهار قاعده را اجرا می‌کند:

1. `not_before` — واژه پیش از درس معرفی، در متن نیاید.
2. نخستین کاربرد — در درس معرفی با `<Term>` بیاید و بعداً دوباره gloss نشود.
3. لاتین ناشناس — هر توکن لاتین ≥۳ حرف باید در واژه‌نامه یا `allowed-latin.txt` باشد.
4. تأیید — با `--require-confirmed` هر واژه باید `status: confirmed` باشد.

## گالری شکل‌ها

`src/pages/_figures-gallery.astro` یک صفحهٔ توسعهٔ اختیاری است و در ساخت نهایی
شرکت نمی‌کند (نام فایل با `_` شروع می‌شود). برای دیدنش موقتاً آن را به
`src/pages/figures-gallery.astro` کپی کنید، `npm run dev` را اجرا کنید و بعد از
بررسی حذفش کنید. این صفحه همهٔ ۲۰ شکل اصلی را با دادهٔ نمونه و یک کلید شبیه‌سازی
«کاهش حرکت» نشان می‌دهد. برای دیدن پنج حالت لنز، همین کار را با
`src/pages/_context-gallery.astro` تکرار کنید.

## دسترس‌پذیری و چاپ

- سند با JS خاموش هم خواناست؛ شکل‌ها و همهٔ گام‌های لنز در حالت نهایی‌اند و کنترل‌ها پنهان.
- `prefers-reduced-motion: reduce` همهٔ حرکت‌ها را حذف می‌کند و شکل‌ها را کامل نشان می‌دهد.
- `src/styles/print.css` نسخهٔ A4 می‌سازد: نوار پیشرفت و کنترل‌ها پنهان،
  فهرست پنهان، شکل‌ها در حالت نهایی، همهٔ گام‌های لنز باز و کدها روشن.
- برای PDF: در کروم `Print → Save as PDF` یا:
  ```bash
  google-chrome --headless --print-to-pdf=dist/book.pdf --no-pdf-header-footer file://$PWD/dist/index.html
  ```

## وضعیت محتوا

همهٔ ۳۵ درس، ۶ بخش، ۳۳ شکل اصلی (۷ تعاملی)، ۲۰ لنز کانتکست و یک آزمایشگاه کامل‌اند.
واژه‌نامه ۴۹ واژه و در وضعیت `confirmed` است. متن authored حدود ۶٬۳۴۰ واژه است؛
بودجه‌ها سقف‌اند، نه سهمیه، و `check-budget.ts` فقط عبور از سقف را خطا می‌داند.
اندازهٔ خروجی حدود ۰٫۸۳ مگابایت است (زیر سقف ۱٫۵ مگابایت).
